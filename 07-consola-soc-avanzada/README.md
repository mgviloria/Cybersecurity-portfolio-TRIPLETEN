# Proyecto 07: Simulador SOC Analyst Console - Investigación Técnica Avanzada

## 🎯 Objetivos del Proyecto
* Priorizar la cola de alertas diferenciando precursores, tráfico legítimo y ataques activos.
* Analizar artefactos técnicos profundos: binarios ofuscados, captura de tráfico (`.pcap`) y descargas de memoria (`memory dumps`).
* Ejecutar comandos de investigación en CLI remota (`netstat`, `Get-ScheduledTask`, `net user`, `reg query`) para inspeccionar hosts a fondo.
* Correlacionar IOCs con plataformas de Threat Intelligence para calibrar la atribución de campañas.
* Reconciliar contradicciones entre fuentes internas (CMDB, baselines, registros de RRHH) mediante triangulación.
* Ejecutar acciones operativas en vivo (aislamiento de hosts, bloqueo de IPs/cuentas y rotación de credenciales en 6 pasos).
* Redactar un informe de investigación dinámico colaborando en tiempo real con supervisión.

## 🛠️ Herramientas y Conceptos
* Análisis de Artefactos (PCAP, Dumps de Memoria, Deobfuscation).
* Investigación por CLI (Windows/Linux Command Line Forensics).
* Threat Intelligence, IOCs y TTPs de campañas.
* Acciones Operativas y Escalado de Incidentes.

## 📝 Resultados y Aprendizajes
Capacidad demostrada para manejar investigaciones de alta densidad técnica, extrayendo evidencia cruda desde binarios y memoria para contener al atacante antes de que genere impacto en la infraestructura.
