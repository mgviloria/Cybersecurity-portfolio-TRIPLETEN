# Proyecto 01: Crear y asegurar una red doméstica virtual

## 🎯 Objetivos del Proyecto
* Identificar las funciones y roles de los dispositivos en una red doméstica.
* Comprender la estructura de la red, la visibilidad entre activos y la segmentación.
* Reconocer errores de configuración comunes y evaluar sus riesgos asociados.
* Explicar y documentar las mejores prácticas de seguridad para mitigar vulnerabilidades.

## 🛠️ Conceptos y Herramientas
* Topología de red y segmentación.
* Análisis de visibilidad de dispositivos.
* Hardening de redes domésticas/SOHO.

## 📝 Resultados y Aprendizajes
Se identificaron fallas de configuración en la estructura de red virtualizada y se definieron controles prácticos para reducir la superficie de ataque y asegurar el tráfico de los activos conectados.
