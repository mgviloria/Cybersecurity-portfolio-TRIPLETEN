# Proyecto 06: Simulador IR Console - Respuesta a un incidente activo

## 🎯 Objetivos del Proyecto
* Realizar triage en tiempo real diferenciando actividad legítima de maliciosa para declarar formalmente un incidente.
* Ejecutar la contención activa de una amenaza para detener la exfiltración de datos bajo presión de tiempo.
* Preservar evidencia volátil siguiendo el orden correcto de captura antes de su pérdida.
* Erradicar la causa raíz, eliminar la persistencia del atacante y verificar la restauración segura del entorno.
* Elaborar un informe ejecutivo, análisis de brechas de control y recomendaciones de mitigación post-incidente.

## 🛠️ Herramientas y Conceptos
* Respuesta a Incidentes en Vivo (*Active Incident Response*).
* Contención, Erradicación y Preservación Forense.
* Análisis de Persistencia y Causa Raíz.
* Análisis de Brechas de Control (*Gap Analysis*).

## 📝 Resultados y Aprendizajes
Toma de decisiones crítica bajo presión para frenar el avance de un atacante, logrando equilibrar la continuidad del negocio con la contención efectiva y la preservación de evidencias clave.
