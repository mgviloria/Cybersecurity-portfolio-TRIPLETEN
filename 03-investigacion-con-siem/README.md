# Proyecto 03: Recolectar y correlacionar evidencia, evaluar riesgos y realizar informe ejecutivo

## 🎯 Objetivos del Proyecto
* Investigar un incidente de seguridad realista utilizando un SIEM (Elastic).
* Correlacionar eventos de autenticación, procesos de endpoint y tráfico de red para reconstruir la cadena de un ataque.
* Reconocer técnicas de movimiento lateral y *Living off the Land*, explicando su complejidad de detección.
* Construir una línea de tiempo (timeline) con Event IDs y un diagrama de flujo del ataque.
* Comunicar hallazgos técnicos, evaluación de riesgos y recomendaciones en un informe ejecutivo claro.

## 🛠️ Herramientas y Conceptos
* Elastic SIEM y Análisis de Logs.
* Correlación de eventos (Autenticación, Red, Endpoints).
* Mapeo de técnicas de ataque (Movimiento Lateral, LotL).
* Redacción de Informes Ejecutivos.

## 📝 Resultados y Aprendizajes
Reconstrucción exitosa de un escenario de ataque complejo mediante el análisis cruzado de logs en Elastic, documentando el incidente con un timeline preciso y recomendaciones de mitigación ejecutivas.
