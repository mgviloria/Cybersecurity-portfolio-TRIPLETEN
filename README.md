# Cybersecurity-portfolio-
Portafolio de proyectos prácticos de ciberseguridad, análisis SOC y respuesta a incidentes (TripleTen).

| # | Proyecto | Descripción Corta |
|---|---|---|
| 01 | Red Doméstica Virtual | Configuración y aseguramiento de red virtual. |
| 02 | Identificación de Alertas | Análisis de alertas SOC y severidad con la tríada CID. |
| 03 | Investigación con SIEM | Correlación de evidencia y timeline en Elastic SIEM. |
| 04 | Credenciales Expuestas | Priorización e hipótesis basadas en logs. |
| 05 | Triage y Correlación | Matriz de triage y nota de alcance sobre tickets. |
| 06 | Respuesta a Incidentes (IR) | Contención en vivo, erradicación y preservación de evidencia. |
| 07 | Consola SOC Avanzada | Análisis de artefactos (PCAP, memoria, binarios) y Threat Intel. |
| 08 | Identidad en la Nube | Investigación de IAM en AWS, políticas JSON y privilegio mínimo. |
